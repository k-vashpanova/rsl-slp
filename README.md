# RSL SLP

**Разработка модели для генерации русского жестового языка**

Аннотация: Данная работа посвящена проблеме перевода текста со звучащего русского языка на русский жестовый язык (РЖЯ). Особое внимание уделено разработке модели в контексте ограниченного количества данных и отсутствия в открытом доступе экспертной разметки видео на РЖЯ, а также учёту различных лингвистических особенностей РЖЯ. В результате данного исследования был разработан пайплайн работы с недавно выпущенным датасетом YouTube-SL-25 и была адаптирована к новым данным модель безглоссового перевода на жестовые языки UniGloR. Также были предложены две модификации модели: (1) модуль CharCNN на основе свёрточных сетей, учитывающий орфографию русскоязычного текста для повышения точности генерации маусинга, и (2) контрастивная функция потерь на основе обратного перевода для контроля семантической адекватности генерируемой жестовой последовательности. Несмотря на невысокие показатели качества модели в связи с малым объёмом обучающих данных, данная работа закладывает основу для будущих разработок в области перевода на РЖЯ методами глубокого обучения.

*Текст и полные данные мигистерской работы размещены по ссылке: https://www.hse.ru/ma/ling/students/diplomas/1055343460*
